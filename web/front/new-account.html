Run your own front

You leave this namespace and stand up your own front on your own box. The installer sets it up; everything it installs is yours from that moment. Pick the tier that matches what you're willing to carry:

Light host — a doorway

Run the front only: a directory, name lookups, verify-and-forward. You store no user content — every post and message lives on pods your users control. Duties: keep the box up, keep names honest, handle detach requests and the complaints that reach the visible domain. If your box dies, names go dark but no data is lost.

Full host — a doorway and a vault

All of the above, plus you supply pods, so you're the custodian of users' actual data on your disk. Adds: backups, growing storage, account recovery, data-protection duties, retention/deletion, and moderating what you store. Mastodon-admin-grade. A user who brings their own pod still keeps custody — the heavy duties apply only to pods you supply.

The offer-pods switch is a tier declaration, not a checkbox. Setup and installer: see netlify/README.md in the FediPod repo.
