The handle, the pod, the identity provider and person-vs-group are what this actor is. Changing any of them means a different actor at a different address — that is a new setup, not an edit.

Where the private data lives is a fact here rather than a setting, because changing it means moving data: stop the agent and run bin/activitypod.mjs state --to <url>.
