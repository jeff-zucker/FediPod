Actor's Handle

The name in your fediverse address. This is permanent. Letters, digits, hyphens, and underscores only.

Actor's Pod

Password is sent once in return for a credential which is stored locally. The password itself is never stored. You may revoke the credential without changing the password.

The subdomain of your pod address, it will become https://YOUR-POD-NAME.your-identity-provider

          Your pod accepts deliveries whether or not this agent is running, so a machine that has been off collects them. The agent is working through them oldest first and will get there on its own — this is only here if you would rather not wait.

          Discarding drops posts, not bookkeeping: follows, unfollows, acceptances and deletions in that period are still applied, so your follower list stays right and nothing stays up that its author took down.
